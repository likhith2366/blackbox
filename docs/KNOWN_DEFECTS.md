# Known defects and limitations

Owner: Evaluation. Each entry says what is wrong, where the evidence is, and what it means in practice.
**Open** = not fixed. **Accepted** = a known limitation that is kept deliberately (usually because the
evaluation code is frozen). Fixed items are not listed (see `docs/QA_FINDINGS.md`).
Last updated 2026-11-20.
